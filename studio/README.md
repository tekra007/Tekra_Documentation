# Tekra Studio — розділ документації

> **Канон — ТЗ** [`spec/tz-lifecycle.md`](spec/tz-lifecycle.md)
> ([PDF](spec/tz-lifecycle.pdf), Oleksii Kulinskyi, 11.09.2026). При розбіжності
> з будь-яким документом нижче пріоритет має ТЗ (D32). Як решта розділу лягає на
> ТЗ — [16-tz-traceability.md](16-tz-traceability.md).

Тут проєктується **Tekra Studio**: створення роботів у вебі + захоплення
елементів екрана через десктоп + виконання роботів на машинах.

Розділ **живий**: пишемо покроково, обговорюємо, повертаємось і правимо.
Код за цими документами **поки не пишеться**.

## Робоча умова

**Прод-даних немає.** Реальних клієнтів зі встановленими роботами не існує, тому
зворотну сумісність зі старою моделлю не тягнемо: проєктуємо так, ніби робимо з
нуля. Ламати наявні таблиці можна.
