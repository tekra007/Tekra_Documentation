# 43. Фаза 9 — `office-com`, Excel: задачі

> Що: провайдер `office-com` (D17) — робота з книгами Excel через **COM API
> справжнього Excel**: усе, що відкриває Excel, читає й робот (`.xlsx`, `.xlsm`,
> `.xlsb`, `.xls`, `.csv`, `.txt`, `.ods`, `.xml`). Відкладалась 2026-11-08 (не було
> Excel на машині розробки); 2026-11-10 — Excel 2021 x64 є, робимо повністю.
> Проєктування — [04-approach.md](04-approach.md) («office-com — окремий випадок»),
> [06-activities.md](06-activities.md), [07-dsl.md](07-dsl.md) (приклад «Excel → 1С»).

## Рішення

| # | Питання | Рішення | Чому |
|---|---------|---------|------|
| 1 | Як працюємо з Excel | **COM** (`pywin32`, уже в Assistant) — справжній Excel, не бібліотека файлів | D17, 04-approach: усі формати, формули перераховуються, макроси, захищені паролем книги — як у людини |
| 2 | Чий Excel | **власний прихований екземпляр** на запуск (`DispatchEx` — окремий процес), `Visible`, `DisplayAlerts`, `ScreenUpdating`, `AskToUpdateLinks` вимкнено; Excel людини (відкриті книги) не чіпаємо. Створюється при першому кроці `office-com`, **закривається наприкінці запуску завжди** (без збереження — зберігає лише `SaveWorkbook` / `CloseWorkbook save`), навіть при помилці / Stop; завис — процес завершується за PID | як браузер у 10A (D19): нічого не лишається вночі, діалоги не блокують робота |
| 3 | Потік | усі виклики COM — у потоці виконання (`CoInitialize` / `CoUninitialize` там само) | COM-об'єкти Excel прив'язані до потоку (STA) |
| 4 | Як кроки знаходять книгу | `OpenWorkbook` / `CreateWorkbook` повертають **дескриптор** — повний шлях файлу (нова книга — `new:1`, `new:2`…), його можна покласти в змінну (`output`); вхід `workbook` в інших кроках **необов'язковий** — типово остання відкрита книга. Аркуш — назва, порожньо — активний | селекторів немає (04-approach): ціль — «книга → аркуш → діапазон»; найчастіший сценарій — одна книга |
| 5 | Активності (`office-com/…`, min Assistant **1.8.0**) | `OpenWorkbook {path, password?, readOnly?, macros?}` → дескриптор; `CreateWorkbook` → дескриптор; `ListSheets` → список назв; `AddSheet {name}`; `ReadRange {sheet?, range?, headers?}` → список рядків; `ReadCell {sheet?, cell}` → значення; `WriteCell {sheet?, cell, value}`; `WriteRange {sheet?, start?, rows, headers?}`; `AppendRow {sheet?, values}`; `RunMacro {macro, arguments?}` → результат; `SaveWorkbook {path?}`; `CloseWorkbook {save?}` (+ необов'язковий `workbook` у всіх, крім Open / Create) | 06-activities + те, без чого «Excel → 1С» не обходиться: аркуші, клітинки, макроси |
| 6 | `ReadRange` | `range` порожньо — заповнена область аркуша (`UsedRange`); `headers` (типово так) — перший рядок дає ключі, рядки — об'єкти (`row.Amount`, як `ExtractTable` у 10A), порожній / повторний заголовок — `column3`; без заголовків — списки. Повністю порожні рядки пропускаються. Читання — одним викликом (`Range.Value`); ліміт — 500 000 клітинок, більше — помилка з порадою вказати діапазон | швидко; однаково з веб-таблицями |
| 7 | Значення | дата → ISO (`2026-11-10`, з часом — `2026-11-10T08:30:00`); ціле число → int; грошовий формат → число; помилки клітинки → текст `#N/A`, `#DIV/0!`…; порожньо → `null`. Запис — як людина вводить: текст `2026-11-10` Excel сам робить датою, текст з `=` — формула | змінні — JSON (D22) |
| 8 | `WriteRange` / `AppendRow` | `rows` — список об'єктів (з `headers` пишеться рядок заголовків) або список списків; `start` типово `A1`. `AppendRow`: об'єкт розкладається за заголовками першого рядка (невідомий ключ — помилка), список — як є; рядок — після останнього заповненого | дописати «звіт» — найчастіша дія |
| 9 | Відкриття | шлях — абсолютний (`C:\…`, `\\server\share\…`) або шаблон; немає файлу — зрозуміла помилка; пароль — з облікових даних (D20, маскується); зовнішні посилання не оновлюються; **макроси вимкнено** (`AutomationSecurity = ForceDisable`), вмикає `macros: true` лише для цієї книги; книга зайнята іншим, а потрібен запис — помилка «file is open by someone else», а не тихе «лише читання» | безпечні типові значення; робот не має мовчки «не зберегти» |
| 10 | `SaveWorkbook` | без `path` — на місце; з `path` — «зберегти як», формат за розширенням (`.xlsx`, `.xlsm`, `.xlsb`, `.xls`, `.csv`, `.txt`, `.ods`, `.pdf` — експорт); наявний файл перезаписується | «зберегти як новий файл» (06-activities) |
| 11 | Можливість `office-com` | Assistant оголошує, лише коли Excel зареєстрований (`Excel.Application` у реєстрі) — без запуску Excel | як `web-cdp` (10A) |
| 12 | Перевірки Studio-back | `path` / `cell` / `range` / `start` — константи перевіряються (абсолютний шлях, адреса `A1` / `A1:D40` / `$A$1`, назва діапазону); `office-com`-крок до `OpenWorkbook` / `CreateWorkbook` — попередження `workbook_not_open` | 14-validation, як `browser_not_open` |

## Задачі

| ID | Що | Де |
|----|----|----|
| **X1** ✅ | каталог `office-com` (Studio-back і Desktop однаково, `catalog_version` 4); перевірки Studio-back | Studio-back, Desktop |
| **X2** ✅ | Assistant: провайдер `office-com` на COM, активності, можливість, закриття Excel, 1.8.0 | Desktop |
| **X3** ✅ | живий прогін: файли різних форматів → читання, запис, дописування, макрос, «зберегти як» → TEST-запуск | усі |

Як зроблено:

- **Каталог** — 12 активностей `office-com/*` (min 1.8.0), `catalog_version` 4, Studio-back і
  Desktop однакові. **Studio-back** — помилки `office_path` (не повний шлях), `office_address`
  (не клітинка / діапазон / назва), попередження `workbook_not_open`.
- **Assistant 1.8.0** — `ExcelComProvider` (COM, власний прихований Excel, закривається
  наприкінці запуску завжди; завис або показав діалог — процес завершується за PID),
  можливість `office-com` — лише коли Excel зареєстрований.
- Виявлено на живому Excel: іменовані аргументи COM мовчки губляться (пароль не доходив —
  Excel питав його прихованим діалогом) → лише позиційні; `C:/…` Excel псує → `normpath`;
  «наївну» дату pywin32 зсуває на пояс → запис ISO-дат як UTC; `AddSheet` перемикав активний
  аркуш → повертаємо попередній.

## Живий прогін (2026-11-10)

Excel 2021 x64. Тестові файли зробив сам Excel: `invoices.xlsx`, `legacy.xls`, `binary.xlsb`,
`export.csv`, `protected.xlsx` (з паролем). Робот RBT-33, 33 кроки → TEST-запуск в Assistant 1.8.0.

| Що | Результат |

Не перевірено: `RunMacro` наживо (на машині вимкнено «довіру до VBA-проєкту» — тест із
