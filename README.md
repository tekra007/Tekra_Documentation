# Tekra — документація workspace

## Для агентів і розробників

1. Прочитайте **[`../AGENTS.md`](../AGENTS.md)** — загальні правила для всіх проєктів у `tekra`.
2. Відкрийте **`/<Проєкт>/docs/`** обраного репозиторію — там будуть (або з’являться) правила саме для FastAPI, Angular або Desktop.

## Підказка щодо контексту між сесіями

- Тримайте **короткі** нотатки в `docs/` (архітектура, команди, «не чіпати X»).
- Великі обговорення краще фіксувати посиланням на issue/PR або з 3–5 рядками резюме в `docs/`.
